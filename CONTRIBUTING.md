# Contributing to Playwright Framework Starter Kit

Thank you for your interest in contributing! This document provides guidelines and instructions for contributing to this project.

## Getting Started

1. Fork the repository
2. Clone your fork: `git clone https://github.com/YOUR_USERNAME/Playwright-Framework.git`
3. Create a new branch: `git checkout -b feature/your-feature-name`
4. Install dependencies: `npm install`

## Development Workflow

1. Make your changes
2. Run tests: `npm test`
3. Run linter: `npm run lint`
4. Format code: `npm run format`
5. Commit your changes with a descriptive message
6. Push to your fork
7. Create a pull request

## Code Style

- Follow the existing code style
- Use TypeScript for all new code
- Run `npm run lint:fix` before committing
- Run `npm run format` to format your code
- Write meaningful commit messages

## Testing

- Add tests for new features
- Ensure all tests pass before submitting PR
- Follow the Page Object Model pattern
- Use descriptive test names

## Pull Request Process

1. Update README.md with details of changes if needed
2. Ensure all tests pass and code is linted
3. Link any related issues in the PR description
4. Wait for review and address feedback

## Questions?

Feel free to open an issue for any questions or concerns.
